# 内分泌系统总表（v1.3.1）

> 本表由 `body/endocrine` 的登记表**自动生成**，不是手写清单 ——
> 手写的清单一定会和代码走偏，而这张表就是从代码里读出来的。

口径：除 `ca`（mmol/L）外，全部激素是**无量纲相对浓度**，1.0 ≈ 常见生理水平。
受体 Kd 一律按 `Kd = 1.6 × 配体参考值` 反解（依据见 `body/endocrine/base.py` 模块头），
n 按受体结构取：核受体与二聚体 2，单体 GPCR 1。两处都**不是**文献里的绝对解离常数 ——
因为本插件的激素量纲本身不是浓度。照抄 nM 级 Kd 会得到恒为 0 的占据率。

## 维护方式

1. 加激素：在对应器官模块的 `HORMONES` 里加一条 `hormone(...)`，
   再在 `BodyState` 里补同名字段（默认值必须等于声明的静息值）。
2. 加受体：在同一模块的 `RECEPTORS` 里加一条 `receptor(...)`，
   占据率由登记表统一按 Hill 计算，**不需要写代码**。
3. 改完跑 `endocrine.registry_audit()`：它会核对「登记了 → 字段存在 →
   默认值等于声明的静息值 → τ 已登记 → 受体有配体且 Kd 为正」五项。
4. 本表由 `_test_artifacts/gen_endocrine_doc.py` 重新生成，不要手改。
