## 三、三套新系统：做了什么、依据是什么

### 1. 血液与免疫

**关键决定：血浆量是状态量，不按占比反推。** 初版写成 血浆量 = 总体水 × 5.7%（看起来"守恒"），
被压力测试打回：那样失血 1 L 血浆只会让血浆量掉 57 mL —— 5.7% 是**基线占比**，不是**边际关系**，
实测 1800 mL 急性失血后血容量只掉 510 mL，把大失血整个抹平了。
现在：血浆量是状态量，失血时与总体水**各按 1:1 扣**，之后由组织间液缓慢回填
（τ=3 h，对应真实的 autotransfusion）。目标仍由总体水与 RAAS/ADH 张力决定。

| 量 | 模型做法 | 依据 |
|---|---|---|
| 血容量 | 血浆 + 红细胞，参考 4000 mL | 成人 60~70 mL/kg [R37] |
| 红细胞生成 | 产出 = 参考周转 × k，k 由 Hb 偏低放大（上限 6 倍）；破坏按 120 天 | [R40][R39] |
| 血红蛋白 | 红细胞体积 × 340 g/L ÷ 血容量 | 导出量，不独立积分 |
| 铁 | 储备 400 mg、吸收 5%~40%、炎症抑制 60% | [R41][R44][R62] |
| 经期失血 | 每周期抽 35 mL 中位的对数正态，>80 mL 属月经过多 | [R42][R43] |
| 血小板 | 250 ×10⁹/L、寿命 7 天、炎症性升高 | [R45] |
| 感染 | 自限高斯曲线（病毒峰值 2.2 天 / 细菌 2.6 天） | 形态与临床病程一致 |
| 白细胞 | 细菌升中性粒、病毒升淋巴；±15% 昼夜波动 | [R46] |
| 炎症 | IL-6（τ=3 h）→ CRP（τ=19 h） | [R47][R63] |
| 发热 | 致热驱动抬高调定点；蓄热期寒战、退热期出汗 | [R48] |
| 生病行为 | 精力↓ 食欲↓ 压力↑ | [R49] |
| 免疫张力 | 睡眠/应激/运动/膳食四因子 | [R50][R51][R52] |

**失血守恒**：V mL 全血 → 血浆部分从总体水扣、钠按 140 mmol/L 扣、红细胞按 V×Hct 扣、
铁按 0.5 mg/mL 扣。四项缺一就会出现"失血了但体液没变"。

### 2. 膳食营养结构

- 311 项食物补齐 纤维 / 钾 / 钙 / 铁 / 维 C。23 项基础食物是逐项真值；288 项扩展走
  "分组画像 + 关键词细分（深色叶菜、全谷物、乳制品、肝脏、柑橘、坚果、油炸、汤粥、清饮）"。
- 按日记账 → 与推荐量（蛋白 1.0 g/kg、脂肪 20~30%、碳水 50~65%、纤维 25 g、
  钾 2000 / 钙 800 / 铁 18 / 维C 100 mg、钠 <2000 mg）比对 → 0~100 分 + 缺乏项标记。
- 评分结构参照 HEI-2015 [R54]；纤维权重参照 25~29 g/天 的荟萃结论 [R53]。
- 派生体重与 BMI（累计能量盈亏 ÷ 7700），**只用于超重/肥胖判定，不反馈给生理**。

### 3. 生活习惯（16 项，纯判定）

判定依据逐项写在 README 第三节与 body/habits.py 模块头。三类**代理指标**在界面上带角标：

| 代理项 | 代理方式 | 为什么只能代理 |
|---|---|---|
| 冥想 / 松弛 | 清醒 + 压力 <35 + 心率低 + 未运动，持续 10~20 分钟 | 模型没有"打坐"这个动作 |
| 久坐 | 本周运动 <60 分钟且今日 <10 分钟 | 模型没有计步与坐姿时长 |
| 工作狂 | 本周 ≥3 天 23:00 后仍清醒且压力 ≥60 | 模型没有工作内容 |

**零副作用**：判定只读状态，唯一写的是它自己的计数器。回归里加习惯前后，
normal 场景的生理曲线逐位一致。

## 四、30 天验证

### 4.1 判据

逐小时记录 37 项指标，判定"异常"的条件：

1. 任何字段 NaN / Inf
2. 生理量越出参考带（心率 30~190、收缩压 70~175、体温 34.5~41、血糖 2~25、血钠 125~160、
   渗透压 255~340、pH 7.10~7.60、Hb 50~200、Hct 15~65、白细胞 0.8~35、体重 35~140 等）
3. 非预期住院（正常/熬夜/感染场景应为 0）
4. 健康 <60 持续超过 6 小时
5. 体重 30 天漂移 >10 kg
6. 关键量 30 天恒定（死字段）
7. 单日同类事件 >40（事件风暴）

### 4.2 结果

| 场景 | 异常 | 住院 | 终态健康 | 说明 |
|---|---|---|---|---|
| 正常 | **无** | 0 | 100 | 90 餐、21 次运动（有氧/力量/瑜伽轮换）、1 个完整月经周期 |
| 熬夜（2:00–9:00 睡） | **无** | 0 | 100 | 补吃生效仍为 90 餐；v1.3.0 同场景是 5 次住院、最低健康 24.7 |

### 4.5 与 v1.3.0 基线对照（正常场景 30 天）

| 项 | v1.3.0 | v1.4.0 | 说明 |
|---|---|---|---|
| 收缩压均值 | 112.3 | 106.8 | 差 5 mmHg，见第四节第 3 条 |
| MAP 均值 | 86.0 | 80.9 | 同上 |

两版的血流动力学回到同一条线（建议审核时抽查这一点）。

**测试抓到的两个真 bug（已修）**：

1. **凝血模型会让大失血"自己止住"**：凝血块饱和后 coag 归零，1800 mL 的失血在约 300 mL 处停下，
   血容量只掉 311 mL。改为"凝血时间随失血量拉长 + coag 留 0.25 地板"，出血一定推进到目标体积。
2. **血浆量按占比反推会让失血被抹平**：见第三节的说明，失血 1 L 血浆只体现 57 mL。
   改为血浆量作为状态量、失血 1:1 扣减、再由组织间液回填。

> 这两条都属于"程序不崩、数值错"，只有做极端测试才暴露 —— 30 天常规回归发现不了。

## 六、已知局限（新增部分）

完整清单见 README 第十一节。本次新增的六条：

1. 血液按总体水换算、不按体重；体重变化不会带动血容量。
2. 免疫只有三类白细胞；感染是自限曲线而非病原体建模，因此"反复感染同一病菌""耐药"不体现。
3. 微量营养素是类别画像（B 级估算），同类内差异被抹平。
4. 三项习惯是代理判定（见第三节）。
5. 意外出血是随机事件，不区分部位、不造成休克。
6. 运动烈度三档只对引擎自主安排生效；外部日程仍按慢跑处理。

## 七、睡眠口径重做（2026-11-26 ~ 11-27 追补）

> 本节的改动属于 **v1.4.0**，`_manifest.json` 一直是 `1.4.0`，未升版。
> 早期文档里出现过的「v1.4.1」是误标，已统一更正。

### 7.1 为什么要重做

用户原话：**「不管中途有没有突然醒过来，只要是一整夜，那就得算在一块。」**

旧实现里根本没有「夜」这一级，只有「连续睡眠区间（bout）」，而夜数直接拿
`len(bouts)` 统计。夜里醒来一次就被数成两夜 —— 服务器实测近 7 天报出 **11 夜**，
实际只有 7 晚。

### 7.2 新增的「夜」聚合层

| 概念 | 判定 | 例子 |
|---|---|---|
| bout | 连续睡眠区间，容忍 0.5 h 间隙 | 23:10 → 02:00 |
| **夜** | 同一 `night_key` 的所有 bout 合并 | 23:10→02:00 + 03:00→07:20 = **一夜** |
| 午睡 | 落在日间且短于 4 h | 13:20 → 14:29 |

夜归属看**入睡时刻**，分界取**正午 12:00**（不是午夜）—— 午夜分界会把
23:00–07:00 的整夜劈成两夜；正午分界则让凌晨 3 点才睡下去仍归属前半夜那一晚。

### 7.3 随之修掉的五个缺陷

| # | 问题 | 症状 | 处置 |
|---|---|---|---|
| 1 | 午睡结算不清账本 | 午睡结束后面板「睡眠结构」一直显示那次小睡 | 午睡分支统一走 `_reset_bout_ledger()` |
| 2 | `_wake_up()` 不记 bout 结束时刻 | 被叫醒后重新入睡，已经睡过的那几个小时**整段丢失** | 唤醒时写 `sleep_bout_end_t` |
| 3 | 周期序号每次入睡归零 | 「第 N 周期」永远显示第 1 个 | 只在换夜时归零，并用 `sleep_bout_cycle_base` 记基线 |
| 4 | 结构行回落到 `dur_*` | 午睡结束后面板显示午睡时长（实测 0.4h/0.2h，直到当晚入睡才恢复） | 改回落「最近一次合格 bout」快照 `sleep_last_struct` |
| 5 | 夜归属依赖可变时钟 | 「最近一夜」把两天并成一夜（实测 16.1 小时 / 2 段 / 5 周期） | 归属取入睡时刻，结算时固化 `bout["night_key"]` |

第 5 条的根因值得记一笔：`_night_key()` 依赖 `clock_offset`，而它是**可变**的
（`sync_clock` 每次同步重写、重启时按墙钟重新对齐）。于是同一段 bout 的归属会
随时间改变，`key=17` 那一夜的跨度因此被撑到 33.6 小时。

### 7.5 已知局限

- **夜间分期图受采样缓冲限制**：曲线只保留最近约 600 个采样点（约 10 小时）。
  刚醒来时看是完整的；隔了大半天再回看昨晚，图上只剩有采样的那一段。这是显示层限制，不影响已结算的睡眠数据。
- **午睡只记时长不入统计**：午睡不进夜间聚合、不参与评分，也不会补记为夜。
