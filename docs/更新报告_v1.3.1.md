## 二、为什么做

### 1. 单文件已经加不动了

v1.3.0 的 `endocrine.py` 一个文件塞了 6 套子系统、214 行。本版要加 38 条激素、45 个受体，
在单文件里做等于放弃可维护性。按器官分科不是审美，是这版能做完的前提。

### 2. APK 的内分泌只用了不到四分之一

`HormoneType` 枚举（`il2cpp_strings.txt:10132`）列了 27 条肽类、11 条类固醇、3 条 Others；
受体枚举（`947/949` 行）列了 50 余个。本版补齐这些，并把"未接线"的项如实标出。

### 3. 受体 Kd 的量纲陷阱

本插件所有激素都是无量纲相对浓度。照抄文献里的 nM 级 Kd，Hill 方程会给出"占据率恒为 0"
—— 看着成立、实际全错，且不报错。故统一口径 `Kd = 1.6 × 配体静息值`（由已发布的 `r_gcr`
反解得到，新旧受体处于同一标尺）。

### 4. 新激素只算不驱动

38 条激素与 45 个受体不进入任何既有反馈回路。不确定增益的回路接进已标定闭环，
是拿用户的身体做实验。

### 5. 三处用户反馈（第②段的来源）

| 反馈 | 真实原因 |
|---|---|
| "体温出现很怪的变化" | 拿"整夜降幅"系数乘逐阶段方波 + 5 分钟时间常数 → 一夜 22 个锯齿 |
| "血压心率也受影响" | 体温经四条隐蔽通路注入全身（心率、入睡潜伏期、CO₂、不显性失水） |
| "情绪是 0 的直线" | 瞬时效价 6 分钟衰减 + 驱动里只有两小项 + 画在 0~100 轴上显得贴地 |
| "睡眠节律太规律" | 窗口 / 周期 / 配比三处死值，七夜分期图几乎重叠 |
| 咖啡因/酒精/运动"好像没影响" | 三者此前对睡眠结构零耦合 |

1. **重标定外诸量逐位一致** —— 解耦后，只扰动体温系数（慢项 0.35→0.45，夜间均温

2. **前 120 分钟与 v1.3.0 逐值一致** —— 证明分岔只发生在重标定起作用之后。
3. **无发散** —— 7 天 10080 采样点，NaN/Inf/超限 0 项。

## 五、未接线与已知边界（如实列出）

| 项 | 状态 | 原因 |
|---|---|---|
| `r_gaba` / `r_nmda` | 未驱动 | APK 有受体，但配体 GABA / 谷氨酸不在 `HormoneType` 枚举，本插件也无该通路 |
| `r_npy` | 未驱动 | 配体 NPY 不在枚举；只登记 PYY 作近似配体 |
| `t3` ← `t4` | 未接线 | T3 仍是昼夜摆动公式，未经 5′-脱碘酶转化；改成真转化等于换掉一条已标定轴 |
| `ang2` ← `ang1` | 两条并行 | ang2 仍由肾素直推；串成一条链会改掉已标定的血管收缩轴 |
| `acth` ← `crh` | 未接线 | ACTH 仍是"皮质醇 × 0.8"；CRH 作为上游量单独计算 |
| REM 期体温调节暂停 | 未建模 | 文献确有此现象（[R36]），但再引入分期耦合会退回锯齿伪像 |
| 心境底色 τ = 4 h | 工程估算 | 未找到可标定的文献 |
| 睡眠夜间变动幅度 | 量级估计 | 未取得"夜间入睡/起床分散 SD"的原始文献 |
