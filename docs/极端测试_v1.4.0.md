# 极端场景测试报告 · v1.4.0

> 测试日期：2026-11-25　｜　被测版本：v1.4.0（基线 v1.3.2）　｜　测试对象：血液 / 免疫 / 急救闭环
>
> 目的：常规 30 天回归只能证明"平常日子不出事"。本报告专门把身体往死里推：
> 大失血、大量饮酒、断水断食、高温叠加，看模型会不会崩、急救会不会真的生效。

## 二、场景 A：急性大失血 2800 mL

出血速率 600 mL/min，目标 2800 mL（约 70% 血容量，IV 级）。**关闭急救**，只看失血本身。

| 时点 | 收缩压 | MAP | 血红蛋白 | 血容量 | 备注 |
|---|---|---|---|---|---|
| 出血前 | 约 105 | 约 79 | 约 135 | 约 4045 | — |
| 出血后 60 分钟 | **约 74** | **约 56** | 约 97 | **约 1743**（−57%） | 失血性休克区间；血红蛋白开始被稀释 |
| 12 小时 | 约 96 | — | **约 56** | 约 3064（回填） | 组织间液回填把血浆补回，血红蛋白被稀释到**重度贫血**，铁储备见底 |

三点值得记：

1. **出血量完整交付**（bleed_done_ml ≈ 2800）。这条曾经不成立：初版凝血模型会在约 300 mL
   处"自己止住"，见第六节。
2. **血红蛋白在出血当刻只掉到约 97，12 小时后才掉到约 56** —— 这是对的：先丢全血
   （浓度守恒），再由组织间液回填稀释。临床上"急性失血早期 Hb 可正常、补液后才见贫血"
   就是这个道理。
3. 血压下降幅度与失血分级一致（70% 血容量 → MAP 约 56），没有崩到 0、没有 NaN。

## 三、场景 B：大量饮酒

1 小时内 10 两 52 度白酒（约 260 g 纯乙醇），随后再补 4 个伏特加 shot。

| 量 | 结果 | 说明 |
|---|---|---|
| 血乙醇峰值 | **约 4.0 g/L** | 真人 3.5 g/L 以上即昏迷/呼吸抑制量级 |
| 呼吸频率最低 | **约 11 次/分**（基线 14） | 本轮新增的呼吸抑制：BAC > 1.0 起线性压低，最多 −30% |
| 核心体温最低 | 约 36.1 ℃ | 酒精散热（旧有机制） |
| 血容量/水 | 略有下降 | 酒精抑制 ADH → 利尿（旧有机制） |
| 急救 | **送医**，出院健康约 73 | 本轮新增：BAC ≥ 3.0 g/L 直接判危重 |
| 异常 | 无 NaN、无穿底 | — |

**这一组是本轮唯一改了模型的场景**：旧实现里血乙醇只影响 ADH 与体温，实测喝到 3.17 g/L 时
呼吸仍是 15.6 次/分、健康 100 —— 等于"酒精没有生理后果"。补了三处：呼吸抑制、
健康惩罚（BAC > 2.0 起）、危重判据（BAC ≥ 3.0 直接可送医）。

## 四、场景 C：急救闭环（开/关对照）

同一份剧本：先 3000 mL 致命失血，再断水断食（关掉进食），30 分钟后追加一次感染。

| | 急救关 | 急救开 |
|---|---|---|
| 住院次数 | 0 | **1** |
| 送医理由 | — | 活动性出血（24 小时约 2990 mL） |
| 是否进过濒死观察 | 否（开关关掉时不判危重） | **是** |
| 健康最低 | 约 11 | 约 23 |
| 终态健康 | **约 11**（停在濒死线） | **约 73**（出院恢复） |
| 是否死亡 | 否（本建模不设死亡） | 否 |

结论：**急救开关是有效的，且两个方向都符合设计** —— 开时按 25 分阈值 + 10 分钟观察窗
送医、出院恢复到 74；关时只停在濒死线，不送医也不会死。

## 五、场景 D：多重应激叠加

45 ℃ 户外（体感负荷 0.9）+ 失血 1200 mL + 3 两白酒 + 一次感染 + 30 分钟中强度运动，观察 8 小时。

| 量 | 结果 |
|---|---|
| 体温峰值 | 约 37.1 ℃（未失控） |
| 收缩压最低 | 约 63 mmHg（失血 + 高温血管扩张） |
| 总体水最低 | 约 40.4 L（−1.6 L，出汗 + 利尿） |
| 血乙醇峰值 | 约 1.15 g/L |
| 是否送医 | 否（未到危重） |
| 异常 | 无 NaN、无越界反弹 |

多重应激下各子系统互相拉扯但都没有发散，说明耦合方向是收敛的（交感↑ → 心率↑ →
耗氧↑ → 产热↑ → 出汗 → 失水 → 血容量↓ → RAAS↑）。

## 六、本轮补的缺口

| # | 缺口 | 症状 | 处置 |
|---|---|---|---|
| 1 | 急性酒精没有生理后果 | BAC 3.17 g/L 时呼吸 15.6、健康 100 | 加呼吸抑制、健康惩罚 |
| 2 | 酒精永远送不了医 | 危重只看健康值，而酒精是"急性"危险 | BAC ≥ 3.0 g/L 直接判危重 |

另外两组缺口（凝血让大失血自己止住、血浆量按占比反推导致失血被抹平）是在 v1.4.0 的
8 组压力测试里发现并修掉的，见 [更新报告 v1.4.0](更新报告_v1.4.0.md) 第 4.7 节。

## 八、已知局限（与酒精相关的新增）

- **不建模耐受与戒断**：长期饮酒不会提高耐受量，停酒也不会出现戒断反应。
- **不建模昏迷/呕吐/误吸**：BAC 4 g/L 时代谢与通气是"变慢"，不是意识消失。
- **不设死亡**：任何场景都不会死，最坏情况是长期停在濒死线。
- **急救只有"送医"一种处置**：没有催吐、洗胃、纳洛酮之类针对性治疗，
  住院只是把指标按一阶惯性拉回安全区。
